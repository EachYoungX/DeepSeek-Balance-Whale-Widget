# Fusion Pixel 字体来源

原项目：[TakWolf/fusion-pixel-font](https://github.com/TakWolf/fusion-pixel-font)。

使用固定发行版 `2026.09.01` 的 `fusion-pixel-font-12px-proportional-otf.woff2-v2026.09.01.zip`，归档 SHA-256 为 `96a105bf90600c9f589629b7e9cf61ab4d498f1a9af33b6ac6f517d217a3393c`。

随包保留未经修改的 `fusion-pixel-12px-proportional-zh_hans.otf.woff2`，以及原归档中的 `OFL.txt`、`LICENSES/`。字体与其组成来源遵循各自随附的许可，项目代码的 MIT 许可独立适用。每个文件的校验值见根目录 `upstream.lock.json` 的 `pixelFont` 字段。

字体从插件本地受保护的路由加载，用户无需安装系统字体，也无需从公网加载字体。
